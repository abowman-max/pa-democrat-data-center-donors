Source package

source-register.pdf is an authored research index, not an original publication.
source-register.csv provides direct links for every registry entry.
house-roll-call-470.pdf and senate-roll-call-260.pdf are user-supplied copies of official Pennsylvania General Assembly roll calls.
Other PDFs are downloaded originals. Some publishers blocked downloads; use the supplied source links in those cases.
Source date is not necessarily the start of a relationship.
No donor-specific personal role is inferred solely from employer affiliation. A lawmaker vote connection does not establish why a contribution was made or the recipient candidate's position.
